## 🚀 Description
MaintiDoc est un assistant destiné aux techniciens de maintenance pour l'interrogation de documentations techniques (pompes HydroFlow et compresseurs AirCore), l'analyse d'images et la gestion sécurisée de tickets via un outil MCP.
